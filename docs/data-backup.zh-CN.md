# 数据、备份、恢复与删除

[English](data-backup.md) · [简体中文](data-backup.zh-CN.md) · [繁體中文](data-backup.zh-TW.md)

## 本地数据范围

应用自有本地数据包括：导入的教材副本、标准化阅读数据、本地全文索引、阅读位置、页面索引状态和结果、来源与修正覆盖层、已完成的对话/消息/引用、笔记、批注、标记、面板偏好、设置、语言、教学指令、确认选择和非敏感服务 profile 元数据。API Key 属于设备本地的 Windows 凭据管理器数据，不属于 SQLite 数据。

## 备份与恢复

“创建备份”会在选择的位置生成一个带版本的 `.tlbackup` 文件。界面会显示估计大小，并提醒归档中包含应用自有教材副本；共享前请自行确认版权和分享权限。

备份包含一致的 SQLite 快照、应用自有原始教材副本、必要的阅读衍生文件、已完成历史、笔记/批注/标记、设置、教学指令、索引、修正和来源信息。每个条目都有相对路径、声明大小和 SHA-256。备份不包含 API Key、凭据标识符、日志、诊断信息、未完成输出、临时图片、缓存、远端临时资源或绝对源路径。它不是云同步，TextbookLens 不会上传备份。

“恢复备份”会先校验格式和版本、大小、哈希、允许的相对路径、SQLite 完整性与兼容性，然后准备原子维护/重启替换。失败时保留当前数据。导入、索引和学习请求必须已经停止。恢复后教材、索引、修正、已完成历史、笔记和设置回到本地；凭据不会随备份转移，需要重新连接 AI 服务。

## 删除一本书、清除全部数据和卸载

“从书库移除”需要单独确认，只删除该书的应用自有副本及衍生文件、索引、修正、对话、笔记和标记，不会修改原始源文件、其他教材或外部 `.tlbackup`。远端资源清理失败会保持可见并允许重试，不会恢复本地数据。

“清除全部数据”不同于删书，也不同于卸载。它始终要求输入界面显示的准确确认文本，目标包括所有 TextbookLens 本地项目：数据库、设置、教学指令、应用自有教材与衍生数据、索引与修正、已完成历史、笔记/批注/标记、缓存、日志、暂存/回收区、远端资源记录和所有 TextbookLens 凭据。操作会先记录可恢复意图；如果凭据清理失败，应用会提示重试，不会声称全部完成。成功后需要重启回到首次使用状态。原始文件、另存的 `.tlbackup` 和应用自有根目录之外的文件不在目标范围内。

卸载不是数据清除保证。0.2.0 已在隔离 Windows 环境完成安装和卸载冒烟测试，但如果目标是删除 TextbookLens 本地数据与凭据，请先使用“清除全部数据”。
