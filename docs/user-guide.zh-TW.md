# TextbookLens 使用手冊

[English](user-guide.md) · [简体中文](user-guide.zh-CN.md) · [繁體中文](user-guide.zh-TW.md)

TextbookLens 是面向 Windows 11 x64 的本機優先 PDF、EPUB、DOCX 教材閱讀器。切換介面語言不會翻譯教材、筆記、問題或回答。

## 安裝與開始使用

1. 開啟[最新版本下載頁](https://github.com/gh615280-maker/TextbookLens/releases/latest)。
2. 一般使用者選擇標準 EXE；集中部署可選擇 MSI。電腦沒有 WebView2 且無法連線時，選擇檔名含 `offline` 的安裝包。
3. 可使用 `SHA256SUMS.txt` 核對安裝檔。
4. 安裝檔尚未程式碼簽章，因此 Windows 可能顯示「未知發行者」。

首次使用從選擇一本教材開始。AI 是選用功能：可用「自動連接本機 AI」接入已安裝的 Ollama/LM Studio，也可設定支援的雲端服務，或只使用本機閱讀功能。

## 匯入與閱讀

1. 在「書庫」按「匯入」或拖入 PDF、EPUB、DOCX。TextbookLens 會先把檔案複製到應用程式自己的本機資料區，再進行解析和索引。
2. 搜尋、閱讀位置、筆記、註解和已完成問答歷程保存在本機。
3. 選取文字後可解釋、舉例、逐步推導、翻譯、提問或建立筆記。
4. 用「框選」選擇公式、圖表、插圖或其他區域。視覺請求首次傳送前會顯示服務商、模型、內容類型、圖片數量和風險。
5. 完成的回答會成為標記和浮動面板。「隱藏」只關閉面板，「停止」才會取消正在執行的請求。可從標記或歷程重新開啟回答。

## 提問與上下文

TextbookLens 依教材保存學習記錄，避免內容散落在多個互不相關的聊天視窗中。每次提問會組合有限的選取內容、目前教材的相關擷取結果、必要的本書歷程、目前教學指令和問題。它不會傳送整個書庫，也不會消除 AI 模型本身的上下文上限。

教材的「學習概覽」完全在本機產生。完成全文準備後可以整本提問，但只擷取目前教材的相關內容。一般 PDF 文字層、EPUB 和 DOCX 的文字擷取不需要 AI 模型。

## 本機與雲端 AI

- **Ollama：** 一鍵探索可啟動本機服務、尋找已安裝文字模型、用合成問題測試模型並建立可用 profile；相容的視覺模型可單獨選擇。
- **LM Studio：** 本機文字接入仍為實驗性功能，真實機器驗證延至 v0.2.1；不承諾視覺輸入。
- **雲端服務：** OpenAI、Gemini、Anthropic、DeepSeek 和 Kimi 需要使用者自己的 API Key，金鑰透過 Windows 認證管理員保存。
- TextbookLens 不安裝執行環境、不下載模型、不附帶模型權重，也不會在本機 AI 失敗後靜默切換到雲端。

詳情見 [AI 服務](ai-services.zh-TW.md)和[離線本機模型](local-models.zh-TW.md)。

## 哪些資料保留本機，哪些可能傳送

| 資料或操作                                 | 本機行為                                  | 是否需要明確操作才傳送 |
| ------------------------------------------ | ----------------------------------------- | ---------------------- |
| 匯入副本、標準化章節、本機索引、閱讀位置   | 應用程式自有檔案和 SQLite                 | 否                     |
| 閱讀、搜尋、筆記、標記、已完成歷程、語言   | 保留本機，可離線使用                      | 否                     |
| 設定、教學指令、profile 中繼資料、確認選擇 | 保留本機；雲端金鑰使用 Windows 認證管理員 | 否                     |
| 選取文字或續問                             | 凍結的選區和有限的本書上下文              | 是                     |
| 選取區域圖片                               | 確認前只在本機暫存有限截圖                | 是                     |
| AI 輔助異常頁索引                          | 本機偵測和驗證                            | 是，只傳送已確認頁面   |
| Kimi Files 全文準備                        | 結果和本機索引留在本機                    | 是，只傳送所選 PDF     |
| 整本提問                                   | 只擷取目前教材的相關內容                  | 是                     |

拒絕確認就不會傳送。記住的選擇只適用於對應 profile 和內容類別，不能授權背景上傳。

## 備份、刪除與還原

「建立備份」產生帶版本的 `.tlbackup`，包含應用程式自有教材副本和本機學習資料，但不包含 API Key、日誌、暫存截圖、絕對來源路徑或未完成 AI 輸出。「還原備份」會先驗證版本、路徑、大小、雜湊和 SQLite 完整性，再安排原子重新啟動替換。

「從書庫移除」只刪除一本應用程式自有副本及其相關本機記錄，不會刪除原始檔案。「清除所有資料」需要輸入正確確認文字，並刪除 TextbookLens 本機資料和認證；另行保存的備份與原始教材不在目標範圍內。解除安裝不等同資料清除。詳情見[資料、備份、還原與刪除](data-backup.zh-TW.md)。

## 目前限制

- 只支援 Windows 11 x64；安裝檔未簽章，也沒有自動更新。
- 尚未實作本機全書 OCR 和本機全書視覺索引。
- 本機視覺模型可能在密集圖表、手寫內容或複雜公式上給出錯誤答案。
- 大型掃描 PDF 可能需要手動調整縮放。
- 服務可用性、額度、價格、保留政策和回答品質由對應服務商或模型決定，不由 TextbookLens 保證。
