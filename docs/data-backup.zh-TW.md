# 資料、備份、還原與刪除

[English](data-backup.md) · [简体中文](data-backup.zh-CN.md) · [繁體中文](data-backup.zh-TW.md)

## 本機資料範圍

應用程式自有本機資料包括：匯入的教材副本、標準化閱讀資料、本機全文索引、閱讀位置、頁面索引狀態和結果、來源與修正覆蓋層、已完成的對話／訊息／引用、筆記、註解、標記、面板偏好、設定、語言、教學指令、確認選擇和非敏感服務 profile 中繼資料。API Key 屬於裝置本機的 Windows 認證管理員資料，不屬於 SQLite 資料。

## 備份與還原

「建立備份」會在選擇的位置產生一個帶版本的 `.tlbackup` 檔案。介面會顯示估計大小，並提醒封存中包含應用程式自有教材副本；分享前請自行確認著作權和分享權限。

備份包含一致的 SQLite 快照、應用程式自有原始教材副本、必要的閱讀衍生檔案、已完成歷程、筆記／註解／標記、設定、教學指令、索引、修正和來源資訊。每個項目都有相對路徑、宣告大小和 SHA-256。備份不包含 API Key、認證識別碼、日誌、診斷資訊、未完成輸出、暫存圖片、快取、遠端暫存資源或絕對來源路徑。它不是雲端同步，TextbookLens 不會上傳備份。

「還原備份」會先驗證格式和版本、大小、雜湊、允許的相對路徑、SQLite 完整性與相容性，再準備原子維護／重新啟動替換。失敗時保留目前資料。匯入、索引和學習請求必須已停止。還原後教材、索引、修正、已完成歷程、筆記和設定回到本機；認證不會隨備份轉移，需要重新連接 AI 服務。

## 刪除一本書、清除所有資料和解除安裝

「從書庫移除」需要單獨確認，只刪除該書的應用程式自有副本及衍生檔案、索引、修正、對話、筆記和標記，不會修改原始來源檔、其他教材或外部 `.tlbackup`。遠端資源清理失敗會保持可見並允許重試，不會恢復本機資料。

「清除所有資料」不同於刪書，也不同於解除安裝。它始終要求輸入介面顯示的正確確認文字，目標包括所有 TextbookLens 本機項目：資料庫、設定、教學指令、應用程式自有教材與衍生資料、索引與修正、已完成歷程、筆記／註解／標記、快取、日誌、暫存／回收區、遠端資源記錄和所有 TextbookLens 認證。操作會先記錄可恢復意圖；如果認證清理失敗，應用程式會提示重試，不會聲稱全部完成。成功後需要重新啟動回到首次使用狀態。原始檔案、另存的 `.tlbackup` 和應用程式自有根目錄之外的檔案不在目標範圍內。

解除安裝不是資料清除保證。0.2.0 已在隔離 Windows 環境完成安裝和解除安裝冒煙測試，但如果目標是刪除 TextbookLens 本機資料與認證，請先使用「清除所有資料」。
