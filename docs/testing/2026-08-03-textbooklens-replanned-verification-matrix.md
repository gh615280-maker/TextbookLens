## 8. Evidence update rules

- `PASS` 只在命令/场景实际完成且无必需工作剩余时填写。
- 环境/服务故障写 `BLOCKED` 和 safe code，不写 provider body。
- 一项 provider 能力官方未知写 `UNKNOWN/DENIED`，不是伪造 PASS/FAIL。
- 每次 checkpoint 记录最终 HEAD；测试中使用自制内容，只记录计数/状态。
