# AI 服务与发送边界

[English](ai-services.md) · [简体中文](ai-services.zh-CN.md) · [繁體中文](ai-services.zh-TW.md)

TextbookLens 支持用户配置的 OpenAI、Gemini、Anthropic、DeepSeek 和 Kimi 官方服务，也支持 [Ollama 本地文字/图片模型和实验性的 LM Studio 文字模型](local-models.zh-CN.md)。请求从 Rust 桌面层发出，浏览器界面不会直接请求服务商，也不能配置生产环境基础地址。

新增或替换云端密钥时，应用会先验证，再提交 Key/profile 更新。云端密钥保存在 Windows 凭据管理器中，不进入 profile 列表、SQLite、前端状态或备份。本地 profile 使用自动发现的回环端口，不需要云端密钥。

## 已配置的能力注册表

下表是实现边界，不是价格、额度、隐私、可用性或未来模型承诺。“页面操作”要求经过验证的文字、图片和严格结构化输出能力；仅支持原生 PDF 并不能启用该操作。应用图片上限为最多 4 张、每张 4 MiB、总计 12 MiB、任一边不超过 4096 像素，每张解码像素不超过 8,847,360。

| 服务商    | 默认模型            | 文字 | 图片   | 原生 PDF | 严格结构化输出 | 页面操作 |
| --------- | ------------------- | ---- | ------ | -------- | -------------- | -------- |
| OpenAI    | `gpt-5.6`           | 支持 | 支持   | 支持     | 支持           | 支持     |
| Gemini    | `gemini-3.6-flash`  | 支持 | 支持   | 支持     | 支持           | 支持     |
| Anthropic | `claude-sonnet-5`   | 支持 | 支持   | 支持     | 支持           | 支持     |
| DeepSeek  | `deepseek-v4-flash` | 支持 | 不支持 | 不支持   | 严格工具支持   | 本地拒绝 |
| Kimi      | `kimi-k3`           | 支持 | 支持   | 不支持   | 支持           | 支持     |

未注册或未知模型在验证后只获得保守的文字能力。图片、PDF 和严格结构化能力默认关闭；应用会在读取凭据或访问网络前拒绝不受支持的操作。不能仅凭服务商名称或模型家族推断能力。

## 发送与确认

每次 AI 调用都必须由用户重新发起。学习请求会发送冻结的选区、必要的本书上下文与历史、当前教学指令和问题。视觉学习只增加明确确认的有限区域/页面图片。可选 PDF 索引只发送已确认的异常页面；Kimi 全文准备只发送明确选择的 PDF；整本提问使用当前教材目录和相关本地检索内容，而不是整本上传。

首次发送区域/页面图片、启动 AI 辅助索引和检测到费用风险的操作，都需要确认服务商、模型、内容类别、图片/页数和风险。拒绝就不会发送。保存的选择只对对应 profile 和类别有效，不能允许后台任务。隐藏回答面板不会取消请求；只有明确点击“停止”才会取消该请求。

Kimi 在输入密钥后通过不含教材内容的 `GET /models` 探测绑定中国或国际区域，没有手动区域选择器。只有明确的认证/区域不匹配才会尝试另一区域；超时、限流、网络和 5xx 错误保留原错误。聊天、Files 上传/轮询/下载和清理都使用绑定区域。

### 本地模型边界

Ollama 和 LM Studio 请求只允许使用数字回环地址，绕过代理并拒绝重定向。应用在每次推理前再次验证模型是否确实为本机模型；Ollama 的 localhost 也可能列出云模型，LM Studio 也可能通过 LM Link 暴露其他设备，因此不能只检查主机名。

Ollama 文字和视觉已进行真实机器验证。LM Studio 文字接入为实验性功能，真实机器验证留到 v0.2.1；本版本不承诺 LM Studio 视觉输入。详情见[离线本地模型](local-models.zh-CN.md)。

## 官方参考与验证边界

协议依据保留在英文 [AI services](ai-services.md)、[ADR 0004](architecture/0004-provider-protocols.md) 和 [ADR 0005](architecture/0005-multimodal-provider-capabilities.md)。能力注册表变更时必须重新核对官方来源和 `last_verified`。

五个云端服务的真实凭据门禁仍未执行；现有证据主要是合成/回环协议测试，不代表当前账号、额度、模型可用性或真实请求一定成功。
