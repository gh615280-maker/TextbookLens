# TextbookLens v0.2.0

[English](v0.2.0.md) · [简体中文](v0.2.0.zh-CN.md) · [繁體中文](v0.2.0.zh-TW.md)

## 主要更新

- 一鍵連接已安裝的 Ollama 模型，支援離線文字問答。
- 可將相容的 Ollama 視覺模型獨立設為圖片區域問答服務，不改變文字預設模型。
- 修正 EPUB 圖片問答的位置保存與重新開啟。
- 隨應用程式提供本機 PDF 字型、CMap 和掃描頁解碼資源，包括 JBIG2 空白頁修正。
- 修正頁底提問表單、書庫卡片／清單排版、目錄跳轉後工具列不可見、縮放把手遮擋，以及教材標記層攔截回答面板按鈕。
- 將 `@xmldom/xmldom` 更新至 0.8.15。

## 安裝包選擇

- 標準 `x64-setup.exe`：建議的小型安裝程式，使用已有 WebView2，缺少時連線下載。
- 標準 `x64_en-US.msi`：用於 MSI 部署。
- 檔名含 `offline` 的 EXE 或 MSI：附帶 Microsoft WebView2，可用於離線安裝。
- `SHA256SUMS.txt`：四個安裝檔的 SHA-256。

所有安裝包都不包含 Ollama、LM Studio 或模型權重。目標平台為 Windows 11 x64，安裝檔未程式碼簽章。

## 邊界與已知限制

- 已在真實機器測試 Ollama 本機文字和視覺。LM Studio 文字仍為實驗性功能，實機驗證延至 v0.2.1；不承諾 LM Studio 視覺。
- 一般 PDF 文字層、EPUB 和 DOCX 的文字擷取不需要模型。
- 尚未實作本機全書 OCR 和本機全書視覺索引。經確認的全書掃描分析仍使用已設定且支援該操作的雲端服務。
- 本機圖片問答每次接受一張有限尺寸圖片。模型呼叫成功不代表密集圖表、手寫內容或複雜公式的答案一定正確。
- 尚未完成真實 RAM/VRAM 耗盡壓力測試，也未涵蓋原生介面中視覺取消／重試的所有組合。
- 大型掃描 PDF 可能仍需手動調整縮放，尚未實作自動符合頁寬。
