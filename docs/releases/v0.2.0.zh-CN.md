# TextbookLens v0.2.0

[English](v0.2.0.md) · [简体中文](v0.2.0.zh-CN.md) · [繁體中文](v0.2.0.zh-TW.md)

## 主要更新

- 一键连接已经安装的 Ollama 模型，支持离线文字问答。
- 可将兼容的 Ollama 视觉模型独立设为图片区域问答服务，不改变文字默认模型。
- 修复 EPUB 图片问答的位置保存与重新打开。
- 随应用提供本地 PDF 字体、CMap 和扫描页解码资源，包括 JBIG2 空白页修复。
- 修复页底提问表单、书库卡片/列表排版、目录跳转后工具栏不可见、缩放手柄遮挡，以及教材标记层拦截回答面板按钮。
- 将 `@xmldom/xmldom` 更新至 0.8.15。

## 安装包选择

- 标准 `x64-setup.exe`：推荐的小安装包，复用已有 WebView2，缺少时联网下载。
- 标准 `x64_en-US.msi`：用于 MSI 部署。
- 文件名含 `offline` 的 EXE 或 MSI：附带 Microsoft WebView2，可用于断网安装。
- `SHA256SUMS.txt`：四个安装包的 SHA-256。

所有安装包都不包含 Ollama、LM Studio 或模型权重。目标平台为 Windows 11 x64，安装包未代码签名。

## 边界与已知限制

- 已在真实机器测试 Ollama 本地文字和视觉。LM Studio 文字仍为实验性功能，实机验证留到 v0.2.1；不承诺 LM Studio 视觉。
- 普通 PDF 文字层、EPUB 和 DOCX 的文字提取不需要模型。
- 尚未实现本地全书 OCR 和本地全书视觉索引。经确认的全书扫描分析仍使用已配置且支持该操作的云端服务。
- 本地图片问答每次接受一张有限尺寸图片。模型调用成功不代表密集图表、手写内容或复杂公式的答案一定正确。
- 尚未完成真实 RAM/VRAM 耗尽压力测试，也未覆盖原生界面中视觉取消/重试的全部组合。
- 大型扫描 PDF 可能仍需手动调整缩放，尚未实现自动适应页宽。

检查结果见仅保留英文的 [v0.2.0 验证记录](v0.2.0-validation.md)，下载见 [GitHub Release](https://github.com/gh615280-maker/TextbookLens/releases/tag/v0.2.0)。
