# TextbookLens v0.2.0

[English](v0.2.0.md) · [简体中文](v0.2.0.zh-CN.md) · [繁體中文](v0.2.0.zh-TW.md)

## Highlights

- One-action connection to installed Ollama models for offline text Q&A.
- A compatible Ollama vision model can be selected independently for image-region questions while the text default remains unchanged.
- Fixed EPUB image-question anchors and reopening.
- Bundled local PDF fonts, CMaps, and scan decoders, including the JBIG2 blank-page fix.
- Fixed the bottom question form, library card/list layout, toolbar visibility after table-of-contents navigation, resize-handle overlap, and textbook marker layers intercepting answer-panel controls.
- Updated `@xmldom/xmldom` to 0.8.15.

## Choose an installer

- Standard `x64-setup.exe` — recommended small installer; uses installed WebView2 or downloads it when missing.
- Standard `x64_en-US.msi` — MSI deployment package.
- An EXE or MSI containing `offline` — includes the Microsoft WebView2 offline runtime for disconnected installation.
- `SHA256SUMS.txt` — SHA-256 values for all four installers.

No package includes Ollama, LM Studio, or model weights. Packages target Windows 11 x64 and are not code-signed.

## Boundaries and known limitations

- Local Ollama text and vision were exercised on a real machine. LM Studio text remains experimental and its real-machine validation is deferred to v0.2.1; LM Studio vision is not promised.
- Normal PDF text layers, EPUB, and DOCX text extraction do not need a model.
- Local whole-book OCR and local whole-book vision indexing are not implemented. Confirmed whole-book scan analysis still uses a configured cloud provider that supports the operation.
- Local image Q&A accepts one bounded image per request. A successful model call does not guarantee a correct answer on dense charts, handwriting, or complex formulas.
- Real RAM/VRAM exhaustion stress testing and every native-UI cancel/retry combination were not completed.
- Large scanned PDFs may still require manual zoom adjustment; automatic fit-to-width is not implemented.
