> 本文汇总 2026-08-03 产品讨论中已经确认的全部改进，用作主控台重新生成实施计划的输入。

## 1. 主控台执行摘要

原产品的本地优先、安全凭据、PDF/EPUB/DOCX 阅读、本地全文索引、五家官方服务商、选段问答、引用、批注和本地历史等核心方向继续保留。

本次重规划必须吸收六组实质变化：

1. **新增自定义长期教学指令。** 用户主动维护全局教学偏好；预设教学方法只用于填充可编辑指令，不做历史人物人格模仿。
2. **新增 AI 辅助本地索引。** 对扫描 PDF、图片公式、表格、图表和低质量文字层，视觉模型按页或小批次解析，结果返回并保存在本地；不把远程索引作为产品依赖。
3. **新增索引质量管理。** 页面级状态、来源标记、自动校验、单页重试、人工纠正、重新索引、断点续传和修正保护属于必要能力。
4. **彻底调整阅读器交互。** 不再使用常驻三栏和固定右侧 AI 面板；改为极简阅读工具栏、文字选择或区域框选、就地操作菜单、可自由拖动缩放并可同时打开多个的浮动回答面板。
5. **重做应用信息架构和视觉。** 顶部一级入口为书库、教学指令、AI 服务、应用语言、设置；整体遵循 Windows Fluent；书库接近 Windows 文件夹；支持简体中文、繁體中文和 English。
6. **改变首次启动顺序。** 从“服务商 → API Key → 教材”改为“选择一本书 → 添加 API Key → 开始阅读”；模型默认自动推荐，高级模型设置后置。

主控台不得继续原样执行旧 Phase 4 Task 9、旧 Phase 5 右侧面板方案或旧首次启动方案。应以当前代码基线为起点重写后续计划。

## 3. 保持不变的核心承诺

以下内容不因本次改进而改变：

1. Windows 11 x64 桌面应用，无账户、无项目云后端；Windows 10 不在 V1 支持或验收范围内，不作兼容性声明。
2. 教材、规范化内容、全文索引、阅读进度、批注和完成对话默认只保存在用户电脑。
3. 用户使用自己的 API Key；项目不代收模型费用，不代理请求。
4. API Key 保存在 Windows Credential Manager，不进入 SQLite、日志、诊断、fixture 或前端持久状态。
5. AI 请求从 Rust 层直接发往所选服务商官方端点。
6. 支持 OpenAI、Gemini、Claude、DeepSeek、Kimi 五家官方服务商。
7. PDF、EPUB、DOCX 的普通本地解析继续优先使用 PDF.js、epub.js、Mammoth。
8. 普通教材检索继续以本地 SQLite/FTS 为基础，不强制引入远程 embedding 或远程向量库。
9. AI 回答必须区分教材原文、教材推断、通用知识、AI 转写和 AI 视觉描述。
10. 失败或取消的回答不创建永久对话标记；只有明确完成并成功提交本地数据库后才持久化。
11. 个人批注完全本地，不读取 API Key，不访问网络。
12. 删除对话或批注不修改用户原始教材文件。

## 4. 相对原始规格和旧计划的变更矩阵

| 领域 | 原始规格/旧计划 | 重规划后的要求 |
|---|---|---|
| 首次启动顺序 | 选择服务商 → API Key → 导入教材 | 选择一本书 → 添加 API Key → 开始阅读 |
| 首次启动模型 | 用户选择或填写模型名 | 默认自动推荐；高级设置中允许修改 |
| 应用导航 | 书库、阅读器内导航、设置；教学能力埋在操作中 | 顶部一级入口：书库、教学指令、AI 服务、应用语言、设置 |
| AI 服务管理 | 设置页中的服务商和模型 | 独立一级页面，默认流程极简，高级设置后置 |
| 教学偏好 | 固定解释/举例/推导模板 | 新增独立“自定义长期教学指令”页面和可编辑预设 |
| UI 语言 | V1 默认 `zh-CN` | 顶部一级语言入口，支持 `zh-CN`、`zh-TW`、`en`，即时切换 |
| 视觉方向 | 只有基础可访问样式 | Windows 11 Fluent 风格，可选 Mica；高对比度、强制颜色、关闭透明效果或效果失败时使用不透明功能回退 |
| 书库 | 教材卡片网格 | 接近 Windows 文件夹：左侧简洁分类、顶部命令栏、大图标/详细列表、拖放导入 |
| 阅读布局 | 左目录 + 中正文 + 右侧固定/折叠 AI 面板 | 阅读时替换为极简工具栏；正文占主区域；目录、搜索、回答按需打开 |
| AI 回答 UI | 固定右侧对话面板 | 应用内浮动面板，可拖动、八向缩放、吸附、同时打开多个 |
| 面板关闭 | 旧 Phase 5 计划中关闭面板会取消请求 | 关闭只隐藏面板；生成继续；停止必须显式点击“停止” |
| 面板数量 | 单个右侧面板 | 多个不同对话面板可同时打开和生成；同一对话仅一个实例；无批量管理入口 |
| 选择范围 | 主要针对可提取文字选段 | 普通文字选择 + 通用矩形框选；框选可覆盖文字、公式、表格、图片和图表 |
| 视觉问答 | 明确排除页面截图和视觉模型 | 用户主动框选后可按需发送区域图像；首次确认，可选择同类操作不再提示 |
| 扫描 PDF | 无文字层即不支持 | 新增 AI 辅助本地索引，视觉模型一次性解析，结果返回本地 |
| 索引来源 | 默认为文件原始文本 | 区分 `local_text`、`ai_transcribed`、`ai_description`、`user_corrected` |
| 索引质量 | 解析成功/失败为主 | 页面级状态、自动检查、待复核、单页重试、人工纠正、版本化重建 |
| 请求预览 | 旧 Phase 5 对普通解释也显示阻断式预览 | 普通文字操作直接执行；上下文/费用预检在后台进行；只有图像、AI 索引或明显费用风险首次阻断确认 |
| 确认偏好 | 每次按安全流程确认 | 首次可选“不再提示”；按服务商和操作类型保存；更换服务商后重新确认 |
| 标记视觉 | 淡色高亮 + 页边图标 | 淡色半透明高亮 + 红点；红点必须有可访问名称，AI/批注仍用文字或图标标签区分 |
| 历史操作 | 点击标记打开右侧面板 | 点击高亮或红点打开/置前对应浮动面板；可继续原对话或删除对话、高亮和红点 |
| 设置页 | AI 服务、主题、数据位置、诊断等 | 只保留阅读体验、数据与隐私、关于；语言、教学指令、AI 服务均移出 |
| 数据能力 | 本地数据和诊断说明 | 新增本地备份/恢复、占用空间、打开数据目录、清除全部数据的产品入口 |

## 5. 最终应用信息架构

### 5.1 非阅读状态顶部导航

```text
TextbookLens｜书库｜教学指令｜AI 服务｜应用语言｜设置
```

- `TextbookLens` 位于左侧。
- 书库、教学指令、AI 服务是独立内容页面。
- 应用语言和设置位于右侧工具区。
- 当前页面不能只靠颜色标识。
- 第一版保留 Windows 原生标题栏和原生窗口控制。

### 5.2 应用语言

必须支持：

```text
简体中文   zh-CN
繁體中文   zh-TW
English    en
```

规则：

- 应用语言是顶部一级入口，不在设置页重复。
- 选项名称始终使用各自语言，不使用国旗。
- 切换立即生效并保存本地，不重启、不调用 AI。
- 首次启动页同样保留语言入口。
- 翻译应用界面、状态、错误和内置模板；不自动翻译教材、批注和历史对话。
- 首次默认跟随 Windows；繁体中文系统使用 `zh-TW`，其他中文使用 `zh-CN`，不支持的系统语言使用 English。

## 6. Windows Fluent 视觉规范

用户已批准整体风格接近 Windows 系统本身，目标是“像 Windows 自带的教材阅读工具”。

### 6.1 系统融合

- 保留原生标题栏、窗口按钮、拖动和缩放行为。
- Windows 11 可以选择使用轻微 Mica；高对比度、强制颜色、关闭透明效果或 Mica 启用失败时回退到不透明纯色背景。
- 跟随系统亮色、暗色、强调色、高对比度和减少动画设置。
- 不以透明效果作为信息层级的唯一手段。

### 6.2 字体和图标

字体优先级：

```text
Segoe UI Variable
Segoe UI
Microsoft YaHei UI
system-ui
```

- 使用 Fluent 风格图标，常用尺寸 16/20 px。
- 返回、搜索、目录、全屏等熟悉功能可以使用图标并提供可访问名称。
- `框选`等不够直观的功能必须同时显示文字。

### 6.3 控件和布局

- 使用接近 Windows 系统的按钮、输入框、下拉菜单、开关、菜单和进度条。
- 圆角克制，建议 4–8 px；边框细、阴影轻。
- 主要操作使用系统强调色，危险操作使用系统错误色。
- 设置使用“名称—说明—右侧控件”的标准行，不堆叠网页后台式卡片。
- 不使用强渐变、霓虹色、手机底部导航、超大胶囊按钮、聊天机器人头像或悬浮球。
- 动效短且克制；遵循系统减少动画设置。

## 7. 书库和教材导入界面

书库参考 Windows 文件资源管理器的熟悉操作方式，但不复制资源管理器的复杂功能区、地址栏和磁盘树。

### 7.1 布局

```text
┌ 导入教材　搜索教材　　　　　　　排序　视图 ┐
├──────────┬─────────────────────────┤
│ 全部教材  │  📕 工程热力学.pdf      │
│ 最近阅读  │  📘 线性代数.epub       │
│ 正在处理  │  📄 控制理论.docx       │
└──────────┴─────────────────────────┘
```

### 7.2 行为

- 左侧只提供全部教材、最近阅读、正在处理。
- 支持大图标和详细列表视图。
- 显示教材名称、格式、阅读进度和索引状态。
- 单击选中，双击或按 Enter 打开。
- 支持把 PDF、EPUB、DOCX 拖入书库。
- `导入教材`使用系统文件选择器。
- 导入后教材立即出现在书库并显示本地复制、解析和索引进度。
- 右键菜单只保留打开、索引状态、从书库删除。
- 删除应用副本不得修改用户原始文件。
- 索引部分失败不阻止阅读；书库显示 `partial` 或 `needs_review`，AI 入口对不可用页面给出说明。

## 8. 自定义长期教学指令

### 8.1 产品含义

它是用户主动编辑、长期生效的教学偏好，不是 AI 自动观察形成的隐藏记忆。

建议说明：

> 设置 AI 长期采用的讲解方式。指令保存在本地，并在发起 AI 学习请求时发送给当前服务商。修改后仅影响新的回答。

### 8.2 页面

参考创建智能体时编写提示词的页面：

- 左侧为大型指令编辑器、字符数、保存状态、预设模板、保存、清空、恢复默认。
- 右侧为可收起的临时测试对话，用于验证当前指令；测试不进入教材历史。
- 不显示 temperature、Top P、原始 system prompt 或 API 参数。

建议第一版最大 1000 个 Unicode 字符。预设包括：

- 启发式追问（苏格拉底式）。
- 先例子后定义。
- 循序渐进推导。
- 故事和比喻。
- 先结论后依据。

历史人物名称只能作为模板说明，不声称复现人格或权威，不生成伪造引语。模板最终写入可见、可编辑的普通文本。

### 8.3 请求规则

- 本地 SQLite 是唯一持久化来源，不使用 `localStorage`。
- 用户可查看、编辑、清空。
- 修改只影响新请求，不改写历史。
- 解释、举例、推导、提问、续问和教材级问题读取该指令。
- 个人批注不读取和不发送该指令。
- 指令计入上下文预算。
- 教材依据、来源区分、引用、范围隔离和安全规则优先于该指令。

## 9. AI 服务页面

AI 服务页面必须尽可能简单、傻瓜式。

### 9.1 首次或添加服务

```text
选择服务商
[ OpenAI ] [ Gemini ] [ Claude ] [ DeepSeek ] [ Kimi ]

API Key
[ •••••••••••••••••••• ]

                 验证并连接
```

- 普通用户只选择服务商、粘贴 Key、验证。
- 默认模型自动从版本化能力表中推荐。
- 模型名、上下文长度和高级能力放入“高级设置”。
- 提供安全的“如何获取 API Key”帮助，不记录 Key。

### 9.2 已连接状态

显示当前服务商、连接状态、自动模型和能力：

```text
Gemini　　　　　　　　　● 已连接
模型：自动推荐
能力：文字、视觉、结构化解析
```

- 可以添加备用服务商。
- 首页只突出当前学习问答服务。
- 学习问答和视觉索引可以使用不同服务商/模型；默认自动选择已配置且能力适合的模型。
- 更换 Key、删除服务商和模型细节属于次要操作。
- 不显示 API URL、原始请求参数或 tokenizer 等实现细节。

### 9.3 确认偏好

页面管理三类偏好：

- 页面/区域图像发送。
- AI 辅助本地索引。
- 明显费用风险。

用户可以恢复所有确认提示。偏好按服务商和操作类型保存，更换服务商后重新确认。

## 10. 首次启动流程

旧顺序被明确替换为：

```text
选择一本书 → 添加 API Key → 开始阅读
```

### 10.1 第一步：选择一本书

- 中央显示拖放区和唯一主要按钮 `选择一本书`。
- 接受 PDF、EPUB、DOCX。
- 选择后立即在本地复制、校验、解析和建立普通索引。
- 本地处理可以在用户填写 API Key 时继续。

### 10.2 第二步：添加 API Key

- 选择五家服务商之一。
- 粘贴 API Key，点击 `验证并继续`。
- 默认模型自动选择；不要求用户理解模型名。
- 验证失败保留已经导入的教材和 Key 输入，不让用户重新开始。

### 10.3 扫描教材的条件分支

若检测到文字层不可靠：

- 在 Key 验证后显示一次 AI 辅助本地索引提示。
- 默认只处理异常页面。
- 显示服务商、模型、页数和费用风险。
- 用户可以拒绝；拒绝后仍允许本地阅读，但相关 AI 索引能力受限。

### 10.4 第三步：开始阅读

- 显示教材名称、本地准备状态和 AI 连接状态。
- 只提供一个主要按钮 `开始阅读`。
- 点击后直接进入教材，不播放多页教程。
- 第一次选择文字或使用框选时，只显示一次短提示。

应用语言入口在三个步骤中均可访问。

## 11. 阅读器整体结构

### 11.1 极简阅读工具栏

打开教材后，完整全局导航被阅读工具栏替换：

```text
← 书库　目录　　　　教材名称 · 当前页/章节　　　　搜索　框选　Aa　全屏
```

- `← 书库`：退出教材。
- `目录`：临时目录面板，跳转后自动收起。
- 中间：教材名和当前位置，点击可跳页/章节。
- `搜索`：当前教材搜索。
- `框选`：矩形区域选择，保留文字标签。
- `Aa`：主题、字体、字号、行距、阅读宽度和 PDF 缩放。
- `全屏`：沉浸式阅读全屏。

PDF、EPUB、DOCX 默认连续滚动。正文保持可读宽度，不随全屏无限拉长。

### 11.2 快捷键

- `Ctrl+F`：当前教材搜索。
- `F11`：进入/退出阅读全屏。
- `Esc`：按状态取消框选、关闭操作菜单或收起当前回答面板。

### 11.3 首次短提示

只显示一次：

> 选中文字或点击“框选”，即可解释、提问或添加批注。

用户完成一次相关操作后永久消失，不使用教程轮播。

## 12. 普通文字选择和区域框选

### 12.1 普通文字选择

- 用户用鼠标或键盘选择文字。
- 应用立即深复制并冻结选区、位置和上下文快照。
- 在选区附近显示统一菜单。

### 12.2 区域框选

1. 点击工具栏 `框选`。
2. 鼠标变为十字光标。
3. 用户拖出矩形。
4. 松开后显示与文字选择相同的菜单。
5. 一次框选完成后自动退出该模式；Esc 可取消。

框选适用于普通文字、公式、表格、图片、图表和混合内容。

### 12.3 统一操作菜单

固定提供：

```text
解释
举例
逐步推导
翻译
提问
批注
```

- 解释、举例、推导直接开始。
- 提问、翻译和批注需要补充内容时，在当前位置显示紧凑输入，不跳页。
- 普通操作不弹出请求预览确认。

### 12.4 视觉内容处理

- 区域内有可靠文字层时，提取文字和本地上下文。
- 公式、图片、图表、混合区域或不可靠文字层可以使用区域图像。
- 必要时同时提供提取文字和区域图像。
- 图像发送遵循首次确认和“不再提示”。
- 定位保存为格式专用锚点和归一化区域，不使用屏幕像素。
- PDF 固定页区域必须稳定恢复；EPUB/DOCX 应绑定可重定位元素/块和归一化区域，不能只记录瞬时屏幕坐标。

## 13. 浮动回答面板

### 13.1 取代固定右侧面板

AI 回答使用应用内浮动工具窗口。操作菜单在选区附近扩展为回答面板；没有常驻 AI 侧栏。

面板显示：

- 原选段或框选区域。
- 当前动作。
- 生成状态和回答正文。
- 教材引用。
- 继续提问输入框。
- 停止、重试、关闭、收起、删除对话等必要操作。

### 13.2 拖动和缩放

- 只能通过标题栏拖动，正文保持可选可复制。
- 四边和四角均可缩放。
- 建议默认约 `400 × 520 px`，最小约 `320 × 240 px`。
- 可吸附窗口边缘，并提供单面板恢复默认位置。
- 记住最后使用的尺寸和位置偏好。
- 应用窗口缩放、最大化、显示器变化后，至少保持标题栏可见。
- 无法容纳最小尺寸时临时吸附为整宽面板。

### 13.3 多面板

- 允许同时打开多个不同对话面板。
- 每个面板独立拖动、缩放、生成、停止、继续提问和关闭。
- 点击面板自动置前。
- 同一对话只存在一个面板实例；再次点击对应标记只置前。
- 多个面板可以同时生成，状态互不影响。
- 不提供全局面板列表、全部收起、平铺或关闭全部。

### 13.4 关闭和生成

- 关闭只隐藏，不删除、不取消。
- 生成期间关闭后请求继续；用户必须点击 `停止` 才取消。
- 面板可以收起为标题/状态条。

该规则与旧 Phase 5“关闭面板即取消”的计划直接冲突，必须重写请求监听和 UI 生命周期，确保隐藏面板时 Rust 事件接收不会被丢弃。

## 14. 回答状态、高亮和历史

### 14.1 状态

```text
准备中
正在生成 + 停止
回答完成 + 继续提问
生成失败 + 重试
已取消 + 重新生成
```

- 未完成内容只在当前运行状态中可见。
- 失败或取消不创建永久标记。
- 只有提供者明确完成且本地事务成功才创建对话、高亮和红点。

### 14.2 永久标记

- 原文字或框选区域留下浅色半透明高亮。
- 高亮边缘显示红点。
- 红点有可访问名称，AI 对话和个人批注仍通过文字/图标标签区分，不能只靠红色。
- 点击高亮或红点打开对应面板；已经打开时置前。
- 多个标记重叠时，只显示紧凑选择列表。

### 14.3 继续和删除

- 历史面板显示原选段、完整对话、引用和继续提问。
- 续问使用当前活动服务商和模型；变更时只做简短提示，不改写历史。
- `删除对话`经确认后原子删除完整本地对话、高亮和红点。
- 删除不修改原教材；关闭面板不等于删除。

### 14.4 重启恢复

- 恢复阅读位置、完成对话、高亮、红点、批注。
- 恢复面板尺寸/位置偏好，但不自动重开上次所有面板。
- 用户点击标记后再打开。
- 未完成生成和未发送草稿不作为完成历史恢复。

确认说明本次内容、服务商、模型、页数和费用风险，并提供：

□ 以后进行此类操作时不再提示

- 不允许后台自动上传；每次仍由明确用户操作触发。
- 更换服务商后重新确认。
- AI 索引任务只在开始时确认一次，不逐批确认。
- AI 服务页面可以恢复所有确认。
- 删除教材、删除数据、清除 API Key 等不可逆操作不受此偏好影响。

## 16. 模型请求和本地对话机制

这一部分主要澄清现有设计，不把模型服务商当作产品记忆层。

### 16.1 每次调用都是新请求

```text
本地教材与索引
  + 同一对话必要历史
  + 自定义长期教学指令
  + 当前问题
  → 临时上下文包
  → 当前服务商
  → 完成后保存回答、模型和引用到本地
```

- 新选区创建新的本地对话。
- 原标记续问仍是新的 API 请求，由应用重发必要历史。
- 不发送所有其他问题，不依赖服务商长期记住会话。
- 教材级问题使用当前教材目录和检索片段，不发送整本书。
- 历史过长时可压缩旧历史，但摘要不能伪装成教材。
- 切换服务商不改写历史。

### 16.2 上下文优先级增补

核心系统约束、自定义长期教学指令、完整当前选段/区域、邻近内容、章节信息、相关本地检索片段、同一对话必要历史共同计入预算。

达到预算时：

1. 先删除低相关片段。
2. 再压缩较早对话历史。
3. 不截断当前选段。
4. 不把视觉摘要当作教材原文。

## 17. AI 辅助本地索引

### 17.1 定义

当扫描 PDF 无文字层，或页面文字、公式、表格、图表无法可靠进入索引时，AI 作为一次性视觉解析器。解析结果返回并保存在本地 SQLite/派生数据中，后续检索不依赖远程索引。

V1 强制覆盖扫描/低质量 PDF 页面。EPUB/DOCX 的文本继续本地解析；其嵌入图片和图表可通过区域框选按需视觉处理。若新计划希望对 EPUB/DOCX 做整书视觉索引，必须单独评估稳定元素定位和范围，不得默认扩大。

### 17.2 流程

```text
本地检测异常页面
→ 用户确认
→ 本地按页渲染
→ 小批次发送视觉模型
→ 严格结构化输出
→ 本地确定性校验
→ 页面级提交/失败/待复核
→ 建立本地规范化块和 FTS 索引
```

- 不把整本书作为一次黑盒请求。
- 批次可取消、暂停、恢复和单页重试。
- 已验证页面独立保留；失败批次不回滚其他成功页。
- 不接受模型生成的稳定 ID；ID 由应用生成。
- 坐标使用归一化页面坐标。

### 17.3 结构化输出

至少能够表达：

- 页码。
- 标题、段落、列表、表格、图注、公式、图形。
- 转写文本。
- 归一化边界。
- 可选 LaTeX。
- 可选表格单元格。
- 可选视觉摘要。

所有返回均为不可信输入，必须有大小、结构、页码、坐标、顺序和所有权校验。

### 17.4 来源

```text
local_text       原始文字层
ai_transcribed   AI 视觉转写
ai_description   AI 视觉解释/摘要
user_corrected   用户修正
```

- `ai_description`只帮助检索和定位，不获得教材原文身份。
- 回答主要依赖 AI 转写时提示识别误差。
- 精确图表问题应定位原页面并按需发送图像，不根据摘要猜测。

## 18. 索引质量管理

### 18.1 用户界面

普通用户只有存在问题时才需要进入。默认只显示需要处理的页面：

```text
索引基本完成
183 页已完成　4 页需要查看　2 页失败

第 42 页　公式可能识别错误　　　查看　重新识别
第 87 页　表格结构不完整　　　　查看　重新识别
第 93 页　未能识别页面　　　　　重新识别
```

查看页面时使用原页面与识别结果并排：

- 左侧原教材页面。
- 右侧可编辑转写、公式 LaTeX 和表格结构。
- 操作：保留原结果、重新识别、保存修正。
- 不显示 JSON、原始模型输出或难懂置信度分数。

### 18.2 页面状态

建议页面状态：

```text
not_required
queued
rendering
sending
parsing
validating
indexed
needs_review
failed
cancelled
```

教材聚合状态：`ready`、`partial`、`needs_review`、`failed`。

### 18.3 自动检查

至少验证：

- JSON/结构完整。
- 页码属于批次且无缺失/重复。
- 坐标为有限数值且在合法范围。
- 内容大小受限。
- 乱码、重复、截断和异常重叠。
- 与部分原文字层的严重矛盾。
- LaTeX 基本语法和长度。
- 表格行列一致性。

模型自报置信度不能替代确定性校验。

### 18.4 人工修正

- 第一版至少允许修正纯文本和 LaTeX。
- 修正作为独立覆盖层保存，来源为 `user_corrected`。
- 检索优先使用修正。
- 重新识别不得静默覆盖修正。
- 冲突时允许保留修正、采用新结果或比较。
- 修正继续绑定原始页码和区域。

### 18.5 版本和重新索引

记录原文件 SHA-256、解析协议/解析器版本、服务商、模型、渲染参数和时间。重新索引默认只处理受影响页面，支持断点续传并保护人工修正。

## 20. 候选数据模型和契约变化

本节是主控台制定迁移和接口计划的最低输入，不要求沿用字段名，但语义必须覆盖。

### 20.1 应用设置

需要增加或调整：

- `ui_language`：允许 `zh-CN`、`zh-TW`、`en`。
- `teaching_instruction`：本地长期教学指令，最大长度校验。
- 学习问答默认 profile。
- 视觉索引默认 profile（可与问答相同）。
- 页面图像、AI 索引、费用风险的确认偏好；建议按 profile 和类别存储，而不是一个全局布尔值。
- 回答面板默认/最近尺寸和可恢复位置偏好。
- 首次阅读短提示是否已完成。

不要在 SQLite 和 `localStorage` 同时保存同一设置。

### 20.2 服务商能力

模型能力表和统一 profile 至少表达：

- 文本对话。
- 图像输入。
- PDF/页面图像能力（若区分）。
- 严格结构化输出或 JSON Schema 能力。
- 上下文长度。
- 视觉请求的保守输入限制。

业务层依赖能力而非供应商条件分支。未知模型不能被猜测为支持视觉或严格结构化输出。

### 20.3 页面级索引

建议新增 `index_pages` 等价实体，记录：

- book/page identity。
- 页面状态。
- 来源。
- provider/model。
- parser/render version。
- 标准化错误码。
- created/updated time。

### 20.4 规范化内容来源

`blocks`、`search_chunks`或旁路来源表必须能区分 `local_text`、`ai_transcribed`、`ai_description`、`user_corrected`。视觉摘要和教材转写不能混为同一来源字段。

### 20.5 人工修正

建议独立 `index_corrections` 等价实体，记录目标页/块/区域、原值、新值、类型、时间和冲突状态。重新索引必须保护该层。

### 20.6 区域锚点

当前选区锚点需扩展为同时支持：

- 文本选区锚点。
- PDF 页面归一化矩形。
- EPUB 元素/CFI + 元素内归一化区域。
- DOCX 稳定块 + 块内归一化区域。
- 区域内容哈希或其他保守回退定位。

重新定位失败时保留历史，不把区域附着到猜测位置。

### 20.7 远程临时资源

优先使用不创建远程持久文件的页面请求。如果某服务商必须创建临时文件，计划必须覆盖资源 ID、删除、失败重试和用户可见状态；远程资源不能成为唯一索引副本。

## 21. AI/provider 层改动

旧统一文本请求接口需要扩展或新增窄接口，以支持：

1. 文本学习请求。
2. 包含区域/页面图像的多模态学习请求。
3. AI 页面结构化解析请求。

要求：

- 五家服务商继续共享业务层契约。
- 只有具备相应能力的 profile 才可用于视觉或结构化解析。
- 供应商请求字段、图像编码、文件上传、结构化输出和终止事件留在适配器内部。
- 视觉解析必须有输出大小、页数、图像分辨率、超时、重试和取消边界。
- 日志、事件、错误和诊断不得包含页面图像、教材文字、提示词、回答或 Key。
- 新的跨服务商 Task 8 测试必须覆盖文本、视觉能力拒绝、结构化输出损坏、取消和完成信号。

主控台应先核实五家服务商当前官方能力；不能假设每家或每个默认模型都支持视觉和 JSON Schema。若只有部分服务商满足视觉索引，UI 必须按能力显示，不虚构统一支持。

## 22. 备份、删除和隐私边界

### 22.1 本地备份

新计划需要定义可恢复的本地备份格式，至少覆盖：

- 本地数据库。
- 批注和完成对话。
- 设置和长期教学指令。
- AI 索引、人工修正和来源元数据。
- 是否包含原教材副本必须明确展示，避免生成超大备份或版权误解。

API Key 不进入备份；恢复后缺少凭据时引导用户重新配置。

### 22.2 删除教材

删除一本教材应删除应用拥有的：

- 原文件副本。
- 派生内容和页面渲染。
- 规范化块和全文索引。
- AI 解析结果和人工修正。
- 对话、批注、高亮和红点。

不删除用户原始导入文件。远程临时资源若存在，执行可观察清理。

### 22.3 清除全部数据

属于不可逆操作，必须单独确认，不受“不再提示”偏好影响。计划必须明确是否同时删除 Windows Credential Manager 中的服务商凭据。

## 23. 重规划后的验收场景

以下场景应加入新的正式规格和验证矩阵。

### A. 首次启动顺序

全新安装先选择教材，本地处理开始；再选择服务商、粘贴并验证 Key；最后点击唯一的“开始阅读”。失败的 Key 不会丢失已导入教材。

### B. 三种应用语言

用户在首次启动和主界面均可从顶部切换简体中文、繁體中文、English。界面立即切换并重启保持；教材和历史内容不被自动翻译。

### C. 长期教学指令

用户保存指令后对两本教材分别发起新请求，两次均包含指令；旧回答不变；清空后新请求不再包含；个人批注全程零网络。

### D. 普通文字解释

用户选择文字，菜单就地出现；点击解释直接生成，不出现普通阻断式预览。完成后创建淡色高亮和红点，失败或取消不创建。

### E. 区域框选文字

用户使用框选覆盖普通文字，应用提取可靠文字并使用同一操作菜单；不因使用框选就强制发送图像。

### F. 区域框选图表

用户框选图表，第一次明确看到将发送的区域、服务商、模型和费用风险；选择不再提示后，同服务商后续主动框选直接执行但仍显示非阻断发送说明。

### G. 多浮动面板

用户打开三个不同历史标记，出现三个独立可拖动缩放面板；可同时生成；点击置前；同一标记重复点击不创建副本；无全局面板管理入口。

### H. 隐藏生成面板

生成期间关闭面板，生成继续且事件接收不中断；重新点击临时/历史入口可看到状态；只有显式停止才取消。完成后原子持久化。

### I. 历史继续与删除

点击高亮或红点打开原对话，继续追问保留历史和模型元数据；删除经确认后对话、高亮和红点一起删除，原教材不变。

### J. 扫描 PDF 拒绝视觉解析

用户拒绝 AI 辅助索引后没有页面上传，教材仍可阅读；不可用 AI 功能给出明确提示。

### K. AI 辅助本地索引

用户确认只解析异常页；小批次返回结果经校验进入本地 FTS；重启、离线或切换服务商后已完成索引仍可使用。

### L. 部分失败与重试

某批页面部分输出损坏；有效页保留，失败页显示 `partial/failed`；单页重试不产生重复块。

### M. 人工纠正

用户修正公式 LaTeX；检索优先使用修正；重新识别不能静默覆盖；冲突进入明确选择流程。

### N. 来源区分

同一回答使用原始文字、AI 转写和视觉摘要时，提示词和界面均区分来源；视觉摘要不被表述为教材原文。

### O. 响应式窗口和全屏

自由缩放、最大化、窄窗口和 F11 阅读全屏下，正文保持可读，顶部栏重排，浮动面板不完全移出可见区，框选和历史锚点保持定位。

### P. 数据备份与恢复

创建本地备份、恢复到干净环境后，教材元数据、对话、批注、索引修正和设置按定义恢复；API Key 不在备份中。

### Q. 删除与泄漏检查

删除教材清除所有应用拥有的相关数据；诊断、日志、fixture、事件和备份元数据检查中不泄漏 Key、教材内容、图像、长期教学指令或回答。

## 24. 新计划必须重写的旧任务

### 24.1 Phase 4

- 保留已完成的文本服务商适配器。

### 24.2 原 Phase 5

必须重写以下假设：

- `SelectionMenu` 同时支持文本选区和区域锚点。
- 普通操作不使用阻断式 Request Preview；预检结果转为非阻断或仅在高风险时确认。
- 固定 `ConversationPanel` 改为可多实例的浮动窗口模型。
- 面板隐藏不取消请求；请求生命周期不能绑定 React 面板是否挂载。
- 标记视觉改为淡色高亮 + 红点，并支持重叠选择。
- 增加区域图像的多模态上下文和确认偏好。
- 多个请求可以同时活动，request registry、事件路由和持久化必须按 request/panel/conversation 隔离。

### 24.3 新增 AI 索引阶段/工作包

建议在文本 provider 能力稳定后、选择学习工作流完成前插入独立工作包，覆盖：

- 页面质量检测。
- 页面渲染和批次计划。
- 视觉结构化解析协议。
- 页面级任务状态和断点恢复。
- 来源和人工纠正数据模型。
- 本地 FTS 合并与替换规则。
- 索引质量管理 UI。
- 隐私、费用、取消、清理和验证。

不要把这一能力分散到 Phase 2、4、5 的零碎任务中而没有单一完成 checkpoint。

### 24.4 原 Phase 6

学习概览和教材级问题可以复用，但必须：

- 读取长期教学指令。
- 区分本地原文、AI 转写、AI 描述、用户修正和用户批注。
- 不把视觉摘要或历史摘要作为教材原文引用。

### 24.5 原 Phase 7

发布审计新增：

- 三语界面和 Windows 高对比度。
- Fluent 响应式布局、原生窗口和全屏。

- 多面板并发和隐藏后继续生成。
- AI 索引的页面级恢复、删除和远程临时资源清理。
- 本地备份不包含 API Key。
- 长期教学指令、页面图像和 AI 解析结果的泄漏检查。

## 25. 建议的新施工依赖顺序

主控台应自行生成详细任务，但依赖关系建议如下：

1. **冻结新正式规格和 ADR。** 合并本文决定，删除旧规格冲突，更新验收场景。

7. **AI 辅助本地索引。** 页面状态、视觉解析、来源、质量、纠正、断点恢复。

## 26. 明确不纳入本次重规划

- 账户、登录、云同步和多人协作。
- 项目服务器代理 AI 请求。
- 项目提供或代付模型额度。
- 远程索引或远程向量库作为唯一知识库。
- 未经用户操作的后台教材上传。
- 把整本书作为一次不可取消、不可逐页恢复的黑盒视觉请求。
- 模型永久记住教材或对话的假设。
- 本地 OCR 引擎不是本次必需项；普通本地文字解析继续优先，扫描页由可选 AI 辅助索引处理。
- 闪卡、间隔重复、自动评分、学习能力画像、在线题库、社区、Agent、语音和 TTS。
- 移动端和网页端。
- 用 AI 视觉摘要冒充教材原文。
- 重新索引静默覆盖用户修正。
- 因用户取消额外提示而允许后台自动上传或取消不可逆操作确认。
