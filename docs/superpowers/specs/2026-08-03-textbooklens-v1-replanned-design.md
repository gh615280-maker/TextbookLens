# TextbookLens V1 重规划正式规格

**状态：** Approved for planning，等待按本规格实施
**规划基线：** `9834e25`（`fix: tighten Anthropic completion policy`）
**生效日期：** 2026-08-03
**替代关系：** 本文是 V1 后续施工的唯一产品规格。它保留 `2026-08-01-local-first-ai-textbook-reader-design.md` 中未冲突的本地优先、安全、文档与学习契约，并替代其中与首次启动、应用导航、阅读器布局、视觉输入、索引、面板、语言和设置相关的冲突条款。旧规格、讨论稿、界面决定和重规划变更包保留为历史输入，不再直接驱动实现。

## 1. 产品目标

TextbookLens 是 Windows 本地优先教材阅读与 AI 学习工具。用户导入 PDF、EPUB 或 DOCX 后，可以离线阅读、搜索、批注和查看历史；只有用户明确发起 AI 操作时，应用才把完成该操作所需的最小文本或图像发送到用户自己配置的官方模型服务。

V1 必须同时做到：

- 教材、索引、对话、批注、教学指令和设置的权威副本在本机。
- API Key 只进入 Windows Credential Manager 和 Rust 请求头，不进入 SQLite、前端状态、日志、诊断或备份。
- 普通带可靠文字层的教材优先使用本地解析和本地 FTS，不依赖 AI 才能阅读。
- 扫描 PDF 或低质量页面可由用户主动启用 AI 辅助本地索引；远端服务不是索引的权威存储。
- 文本选择和矩形区域选择共享学习操作，但图像发送、AI 索引和明显费用风险遵守首次确认。
- AI 回答使用可并发的应用内浮动面板；隐藏面板不取消生成，只有显式停止才取消。
- 界面支持简体中文、繁體中文和 English，并采用克制的 Windows Fluent 视觉。

## 2. V1 范围

### 2.1 必须实现

- Windows 11 x64 桌面应用，支持 PDF、EPUB、DOCX 导入、复制、解析、阅读和本地搜索。
- 书库、教学指令、AI 服务、应用语言、设置五个非阅读状态一级入口。
- 三语界面即时切换；教材、批注和历史内容不自动翻译。
- Windows Fluent 响应式应用框架、原生窗口、系统主题、高对比度和减少动画支持。
- 书先于 Key 的首次启动流程。
- OpenAI、Gemini、Anthropic、DeepSeek、Kimi 官方服务；至少文本学习契约统一，视觉和结构化能力按模型能力门控。
- 长期教学指令、可编辑预设和不进入教材历史的临时测试。
- PDF 扫描/低质量页的 AI 辅助本地索引、质量管理、断点恢复、单页重试和人工纠正。
- 普通文字选择与 PDF/EPUB/DOCX 稳定区域选择。
- 解释、举例、逐步推导、翻译、提问和完全本地的个人批注。
- 多浮动回答面板、并发生成、隐藏继续、明确停止、继续追问、删除和重启后历史恢复。
- 教材级学习概览和教材级问题。
- 本地备份/恢复、存储占用、打开数据目录、删除教材、清除全部数据和脱敏诊断。
- A–Q 验收场景和 Windows 发布门禁。

### 2.2 明确不实现

- 账户、登录、云同步、多人协作、移动端或网页端。
- Windows 10 支持或验收；V1 不作 Windows 10 兼容性声明。
- 项目服务器代理、项目提供模型额度或代付模型费用。
- 远程索引或远程向量库作为唯一知识库。
- 未经用户操作的后台教材上传。
- 整本书一次性、不可取消、不可逐页恢复的视觉请求。
- 假设模型永久记住教材、指令或对话。
- 本地 OCR 引擎；V1 的扫描页增强使用可选 AI 视觉解析。
- 闪卡、间隔重复、自动评分、学习画像、在线题库、社区、Agent、语音或 TTS。
- 用 AI 视觉摘要冒充教材原文，或重新索引静默覆盖人工修正。

## 3. 固定技术与工作区边界

- 前端：React 19、TypeScript、Vite、React Router、React Aria、PDF.js、EPUB.js、Mammoth。
- 桌面和后端：Tauri 2、Rust、Tokio、SQLx、SQLite/FTS5、Windows Credential Manager。
- AI 网络请求只从 Rust 发出；前端禁止直接请求模型服务或配置生产 base URL。
- 依赖版本精确锁定；新增依赖必须有官方来源、必要性说明、许可证和敏感文件检查。
- 迁移只使用新的前向迁移，不重写 `0001`–`0005`。
- 不删除、移动、格式化、暂存或提交工作区内与 TextbookLens 无关的 DOCX、PNG、Python、审计目录和用户文件。
- 每个提交显式暂存目标文件；禁止 `git add .`、宽泛清理或破坏性 Git 命令。

## 4. 本地优先与数据边界

### 4.1 权威副本

SQLite 和应用拥有的数据目录保存：

- 教材副本、规范化章节/块、本地全文索引和阅读位置。
- 页面级 AI 索引状态、已验证转写/描述、来源、版本和人工修正。
- 完成的对话、消息、引用、批注、标记和面板偏好。
- 服务商 profile 的非敏感元数据、确认偏好、语言、阅读设置和教学指令。

Windows Credential Manager 单独保存 API Key。`localStorage` 不保存上述权威设置或业务数据。

### 4.2 网络发送规则

- 本地导入、阅读、搜索、批注、语言切换、备份和恢复不需要 AI 网络。
- 每次 AI 调用是独立请求。应用从本地重新组装必要的教材片段、同一对话历史、长期教学指令和当前问题。
- 只在用户发起学习、视觉问答、教学指令临时测试或 AI 索引时发送内容。
- 切换服务商不改写历史；续问使用发送时的活动学习 profile。
- 日志、错误、事件、诊断和崩溃信息不得包含 Key、教材正文、页面图像、提示词、回答、批注或教学指令。

## 5. 信息架构、语言和视觉

### 5.1 非阅读状态

顶部导航固定为：

```text
TextbookLens｜书库｜教学指令｜AI 服务｜应用语言｜设置
```

- 当前项同时使用文字、形状或语义状态标识，不能只靠颜色。
- 语言和设置位于右侧工具区；语言不在设置页重复。
- 首次启动保留语言入口。

### 5.2 应用语言

严格支持 `zh-CN`、`zh-TW`、`en` 三个枚举值。

- 首次默认读取 Windows 语言：繁体中文映射 `zh-TW`，其他中文映射 `zh-CN`，其余映射 `en`。
- 切换立即更新路由页面、菜单、状态、错误和内置模板并写入 SQLite，不重启、不调用 AI。
- 三个选项始终显示为“简体中文”“繁體中文”“English”，不使用国旗。
- 翻译仅覆盖应用 UI；不改变教材、用户批注、历史问题或历史回答。
- 任何新增消息键必须在三种语言中同时存在，缺键在测试和构建时失败。

### 5.3 Fluent 视觉

- 保留 Windows 原生标题栏、窗口按钮、拖动和缩放。
- Windows 11 可选择使用轻微 Mica；高对比度、强制颜色、关闭透明效果或 Mica 启用失败时回退为不透明纯色，功能不得依赖透明效果。
- 跟随系统亮/暗主题、强调色、高对比度、文本缩放和减少动画。
- 字体优先 `Segoe UI Variable`、`Segoe UI`、`Microsoft YaHei UI`、`system-ui`。
- 使用 16/20 px Fluent 风格图标；不熟悉的操作（例如框选）同时显示文字。
- 圆角 4–8 px、细边框、轻阴影；不使用强渐变、霓虹、手机底栏、聊天头像、悬浮球或超大胶囊按钮。
- 在窄窗口、最大化、全屏、125%–200% 缩放和高对比度下仍可完成核心流程。

## 6. 书库与导入

- 书库接近 Windows 文件夹，左侧仅有“全部教材”“最近阅读”“正在处理”。
- 顶部命令栏提供导入、搜索、排序和大图标/详细列表切换。
- 显示教材名称、格式、阅读进度、导入状态和索引状态。
- 单击选择，双击或 Enter 打开；支持 PDF/EPUB/DOCX 拖放和系统文件选择器。
- 选择文件后立即复制到应用数据目录并显示复制、解析、本地索引进度。
- 右键菜单仅保留打开、索引状态、从书库删除。
- 索引为 `partial` 或 `needs_review` 时仍可阅读；不可用页面的 AI 操作显示具体限制。
- 删除应用副本不修改用户原始文件。

## 7. 首次启动与 AI 服务

### 7.1 首次启动顺序

固定为：

```text
选择一本书 → 添加 API Key → 开始阅读
```

1. 用户选择或拖入一本教材；本地复制、解析和本地索引立即开始。
2. 用户选择五家服务商之一并粘贴 Key；应用自动选择版本化能力表中的推荐文本模型。
3. 验证失败不删除已导入教材，也不把 Key 写入前端持久状态。
4. 如果教材页文字层不可靠，在 Key 验证后显示一次可拒绝的 AI 辅助索引确认；拒绝后仍可阅读。
5. 准备页只提供“开始阅读”主要操作。首次选择文字或框选时显示一次短提示，不使用教程轮播。

### 7.2 AI 服务页面

- 普通添加流程只有服务商、API Key、验证并连接。
- 模型名、上下文长度和高级能力在“高级设置”中；默认显示“自动推荐”。
- 页面显示当前学习 profile、可选视觉索引 profile、连接状态和经过验证的能力。
- 可添加备用服务商、替换 Key、删除 profile、切换学习/视觉默认 profile。
- 页面管理“区域/页面图像”“AI 辅助索引”“明显费用风险”三类确认偏好。
- 确认偏好按 profile 和操作类别保存；更换 profile 后重新确认；用户可恢复全部提示。
- 未知模型只获得已验证的保守文本能力；不得推测其支持图像、PDF 或严格结构化输出。

### 7.3 原子凭据更新

- 验证成功后才写 Windows Credential Manager 和 profile 元数据。
- Key 写入、数据库更新和旧 Key 删除使用补偿流程；任一失败保持旧 profile 可用或回滚新 Key。
- 列表命令只返回 `available|missing`，不返回 Key、Key 长度、前后缀或 credential key。
- 删除 profile 清理其凭据；若是活动 profile，数据库与 UI 原子选择安全回退或进入未配置状态。

## 8. 长期教学指令

- 教学指令是用户可见、可编辑、长期生效的全局偏好，不是隐藏画像或模型记忆。
- SQLite 是唯一持久化来源；最大 1000 个 Unicode 标量值，空字符串表示关闭。
- 页面包含大型编辑器、字符数、保存状态、保存、清空、恢复默认和五种可编辑预设：启发式追问、先例子后定义、循序推导、故事与比喻、先结论后依据。
- 预设只填入普通文本，不声称模拟人物、不生成伪造引语。
- 可收起的临时测试对话使用当前学习 profile，但不创建教材对话、消息、引用或标记。
- 修改只影响新请求。解释、举例、推导、翻译、提问、续问和教材级问题读取它；个人批注不读取。
- 教学指令计入输入预算，优先级低于核心安全、来源、引用和 book isolation 规则。

## 9. 阅读器与选择

### 9.1 阅读状态

打开教材后，全局导航被极简工具栏替换：

```text
← 书库　目录　　　教材名称 · 当前页/章节　　　搜索　框选　Aa　全屏
```

- 目录和搜索按需打开；跳转后目录自动收起。
- PDF、EPUB、DOCX 默认连续滚动；正文保持可读宽度。
- `Ctrl+F` 打开教材搜索，`F11` 切换全屏，`Esc` 按优先级取消框选、关闭菜单或收起当前面板。
- `Aa` 管理主题、字体、字号、行距、阅读宽度和 PDF 缩放。

### 9.2 文字选择

- 用户完成鼠标或键盘选择时，前端立即深复制文字、格式专用锚点和上下文标识；之后滚动、重定位或改变浏览器 selection 不改变请求。
- 选区附近显示统一菜单：解释、举例、逐步推导、翻译、提问、批注。
- 解释、举例、推导直接开始；翻译、提问和批注只显示紧凑输入，不跳页。
- 普通文字操作不显示阻断式 Request Preview。

### 9.3 区域选择

- 点击“框选”后拖出一个矩形，松开即冻结格式专用区域锚点并自动退出框选模式；`Esc` 取消。
- 区域可覆盖文字、公式、表格、图片、图表或混合内容。
- 有可靠文字层时优先提取文字；公式、图片、图表、混合区域或不可靠文字层可同时提供有界区域图像。
- 坐标一律相对稳定页面、EPUB 元素/CFI 或 DOCX 稳定块归一化，绝不保存屏幕像素。
- PDF 保存页号和归一化矩形；EPUB 保存 CFI/元素与元素内矩形；DOCX 保存稳定块和块内矩形；都保存内容哈希作保守回退。
- 重定位不唯一或失败时只在历史中显示，不把标记附着到猜测位置。

### 9.4 发送确认

首次发送区域/页面图像、首次启动 AI 索引或检测到明显费用风险时，确认页显示内容类别、服务商、模型、页数/图像数和费用风险，并允许选择“以后同类操作不再提示”。

- 取消提示后，同一 profile、同一类别的用户主动操作可直接执行，但仍显示非阻断发送摘要。
- 用户每次仍需主动发起；偏好不能授权后台上传。
- 更换 profile 后重新确认；不可逆删除和清除操作永远单独确认。

## 10. Provider 统一契约

业务层只依赖三种窄操作：

1. 文本学习流。
2. 带一个或多个有界区域/页面图像的多模态学习流。
3. 返回版本化严格结构的页面分析。

能力表至少包含文本对话、图像输入、PDF/页面图像、严格结构化输出、上下文长度、默认/最大输出和保守图像限制。能力状态是明确支持、明确不支持或未知；只有明确支持才能进入视觉/结构化流程。

- 五家文本适配器共享 `TextDelta`、`Usage`、`Completed` 和标准错误/取消语义。
- 视觉编码、供应商 schema、文件上传、终止事件和隐藏 reasoning 字段留在 Rust 适配器内部。
- 只有供应商明确成功终止才产生一个 `Completed`；EOF、`[DONE]`、usage、最后一段文本或 HTTP 200 本身都不代表成功。
- 取消后不再产生 delta、usage 或 completion。
- 页面分析结果是有界、不可信输入，必须经过版本、大小、页码、所有权、顺序、坐标和类型验证。
- 优先使用不创建远程持久文件的请求。若官方协议必须创建临时资源，记录 opaque resource ID 和清理状态；成功、失败、取消、删除教材和启动恢复都尝试可观察清理。

## 11. AI 辅助本地索引

### 11.1 适用范围

- V1 强制覆盖扫描或低质量 PDF 页的可选视觉解析。
- EPUB/DOCX 正文继续本地解析；其图像和图表使用按需区域问答，不默认扩大为整书视觉索引。
- AI 是一次性解析器；成功结果回到本地并进入本地检索，后续搜索不依赖远端。

### 11.2 流水线

```text
本地质量检测
→ 用户一次确认
→ PDF.js 本地按页渲染
→ 小批次视觉请求
→ 严格结构化返回
→ 本地确定性验证
→ 每页独立提交/待复核/失败
→ 本地来源化块与 FTS
```

- 每批页数、图像字节、像素、响应、超时和并发均有保守上限。
- 支持取消、暂停、恢复、失败页重试和单页重新识别。
- 已提交页面不因其他页失败而回滚；失败批次不生成半页索引。
- 模型不得决定稳定 ID；应用根据 book、page、run 和 ordinal 生成。
- 应用关闭或崩溃后，将 `rendering|sending|parsing|validating` 恢复为可重试状态，不伪造完成。

### 11.3 页面状态和结果

页面状态：`not_required`、`queued`、`rendering`、`sending`、`parsing`、`validating`、`indexed`、`needs_review`、`failed`、`cancelled`。教材聚合状态：`ready`、`partial`、`needs_review`、`failed`。

结构化页面内容至少表达页码、标题、段落、列表、表格、图注、公式、图形、转写文本、归一化边界、可选 LaTeX、可选表格单元格和可选视觉描述。

确定性验证至少覆盖：

- JSON/schema 和总大小。
- 批次页码无越界、遗漏或重复。
- 有限且位于 `[0,1]` 的坐标、稳定排序和所有权。
- 乱码、严重重复、异常重叠、截断和与已有文字层的严重矛盾。
- LaTeX 长度/基本语法和表格行列一致性。

模型自报置信度不能替代验证。

### 11.4 来源与人工修正

所有检索候选必须有一种来源：

- `local_text`：原文件可靠文字层。
- `ai_transcribed`：AI 对页面可见文字/公式的转写。
- `ai_description`：对图形、表格或版面的辅助描述，不具教材原文身份。
- `user_corrected`：用户对转写文本或 LaTeX 的显式覆盖。

索引质量页面默认只显示待复核或失败页，可并排查看原页面与可编辑结果。人工修正存为独立覆盖层，绑定页和区域；检索优先使用修正。重新识别遇到修正时必须让用户选择保留修正、采用新结果或比较，不能静默覆盖。

回答主要依赖 AI 转写时提示可能存在识别误差；精确图表问题重新定位原区域并按需发送图像，不从 `ai_description` 猜测。

## 12. 学习上下文、引用与提示词

### 12.1 上下文优先级

选择学习请求按以下顺序装包并计入同一保守预算：

1. 核心系统约束和来源/引用规则。
2. 长期教学指令。
3. 完整当前文字选择或区域内容。
4. 邻近可靠文本和当前/祖先章节信息。
5. 同教材相关本地检索片段，带来源和定位。
6. 同一对话的必要历史；过长时可压缩更早历史并明确标为摘要。
7. 当前问题和输出预留。

达到预算时先删除低相关检索片段，再压缩较早历史；不截断当前选择，不跨教材，不把批注、历史摘要或视觉描述标为教材原文。

### 12.2 回答规则

- 区分教材陈述、合理推断和一般知识。
- 引用只指向请求中实际提供的教材来源，并能恢复到页/章节/块/区域。
- 来源是 `ai_transcribed` 或 `user_corrected` 时可引用但显示来源；`ai_description` 只能作为辅助，不能成为逐字教材引用。
- 上下文不足时明确说明，不编造教材结论。
- 可显示 Markdown、KaTeX 和学生可见推导步骤，但不请求、传输或保存隐藏 chain-of-thought。

## 13. 浮动面板、请求与持久化

### 13.1 面板模型

- AI 回答面板从选择菜单原地扩展，默认约 `400×520`，最小约 `320×240`。
- 仅标题栏可拖动，四边和四角可缩放；正文保持可选择/复制。
- 可吸附应用窗口边缘，窗口尺寸或显示器变化后至少保持标题栏可见；空间不足时临时整宽。
- 允许多个不同对话面板同时存在和生成；同一对话只有一个实例，再次点击标记只置前。
- 不提供面向用户的全局面板列表、全部收起、平铺或全部关闭。
- 面板可收起。关闭只隐藏，不删除、不取消；显式“停止”才取消。

### 13.2 请求生命周期

状态严格为：

```text
preparing → streaming → completed | failed | cancelled
```

- Rust request registry 按 `request_id` 隔离取消令牌、累积上限、终止和持久化。
- 前端全局请求 store 独立于面板挂载；隐藏或关闭面板不会丢失事件。
- 每个事件携带 request ID 和单调序号；重复、迟到和终态后事件被拒绝。
- 多请求可并发；停止一个请求不影响其他请求。
- 流式文本只在内存中可复制。只有 provider 明确 `Completed` 且本地事务成功才成为历史。

### 13.3 原子保存和标记

- 新选择完成时，会话、初始用户消息、助手消息、引用和 AI annotation 在一个 SQLite 事务中提交。
- 续问完成时，一个用户/助手消息对原子追加到原会话，不创建第二个 annotation。
- 失败、取消、输出越界、结构错误或数据库失败不创建永久消息、高亮或红点。
- 完成标记使用淡色半透明高亮和红点；红点具有可访问名称，AI 对话和个人批注另有文字/图标标签。
- 重叠标记显示紧凑选择列表。
- 点击标记打开或置前面板；无法恢复锚点的会话保留为 history-only。
- 删除对话需确认并原子删除对话、消息、引用、annotation、高亮和红点，不修改教材。
- 重启恢复阅读位置、完成历史、标记和面板尺寸/位置偏好，但不自动重开所有面板，不恢复未完成输出或草稿。

## 14. 个人批注与教材级学习

- 个人批注完全本地，不能构造 provider、获取凭据或打开网络。
- 批注可绑定文字或区域锚点；空白批注不保存。
- 学习概览使用确定性本地聚合，不调用 AI 才能显示。
- 教材级问题只发送目录、相关本地检索片段、长期教学指令和同一教材级对话历史，不发送整本书。
- 概览和教材级检索保留 `local_text|ai_transcribed|ai_description|user_corrected|user_note|history_summary` 区分。

## 15. 设置、备份、删除与恢复

### 15.1 设置页面

设置仅包含：

- 阅读体验：主题、字体、字号、行距、阅读宽度、PDF 默认缩放。
- 数据与隐私：数据位置、打开数据目录、占用空间、创建备份、恢复备份、清除全部数据、脱敏诊断和发送边界说明。
- 关于：版本、更新入口、项目地址、开源许可证和第三方许可证。

语言、教学指令和 AI 服务不得在设置页重复。

### 15.2 本地备份

- V1 备份是单个版本化 `.tlbackup` 本地文件，明确包含应用拥有的教材副本，因此创建前显示预计大小和版权/共享提醒。
- 备份包含一致的 SQLite 快照、教材副本、完成对话/批注、设置、教学指令、AI 索引、人工修正、来源元数据和必要派生文件。
- 不包含 API Key、Windows credential identifier、日志、诊断、未完成输出、临时页面图、缓存或远程临时资源。
- 每个条目有相对路径、大小和 SHA-256；禁止绝对路径和目录穿越。
- 恢复先解包到应用临时目录，验证格式版本、大小、哈希、SQLite 完整性和迁移兼容性，再在无活动导入/索引/学习请求的维护模式下通过重启完成原子交换；失败保留当前数据。
- 恢复后凭据仍以本机 Credential Manager 为准；缺失时引导重新配置。

### 15.3 删除

删除教材需要单独确认，并删除应用拥有的教材副本、派生/页面渲染、规范化内容、全部本地索引、AI 结果、修正、对话、批注、标记和相关远程临时资源记录；不删除用户原始文件。远程清理失败可重试且可见，但本地教材不因远端失败复活。

“清除全部数据”明确包含所有 TextbookLens 数据和 TextbookLens 写入 Windows Credential Manager 的全部服务商凭据。确认界面逐项列出这一结果，不受“不再提示”影响；成功后重启到首次启动。用户另行保存的 `.tlbackup` 文件不删除。

## 16. 错误、安全和可访问性

- 对外错误使用稳定代码和本地化安全文案；vendor body、路径、Key、教材内容和提示词不进入 DTO。
- 书、profile、request、page、panel 和 conversation 均做所有权/范围校验；所有查询显式按 `book_id` 隔离。
- 文本、JSON、图像、页数、输出、IPC、数据库字段和文件条目都有 Unicode/字节/数量上限，拒绝而非静默截断必需内容。
- 所有取消操作是幂等的；终态后不能再发事件或提交。
- 所有交互可用键盘完成；焦点、菜单、对话框、浮动面板、状态和错误有正确名称/角色/实时区域。
- 高亮、来源、状态和当前项不能只靠颜色；高对比度和减少动画下保留功能。

## 17. 验收场景

### A. 首次启动顺序

全新安装可选择一本书、在本地处理期间添加一个有效 Key、使用自动模型并直接开始阅读；验证失败不丢书。

### B. 三种应用语言

在首次启动、书库、阅读器和设置中切换三种语言立即生效并重启保持；教材与历史内容不被翻译。

### C. 长期教学指令

保存一条指令后，新解释、续问和教材级问题包含它；旧回答不改变；临时测试不进入教材历史。

### D. 普通文字解释

选择可靠文字并点击解释时不出现阻断预览；冻结的选择不受滚动影响；完成后原子出现回答、高亮和红点。

### E. 区域框选文字

框选包含可靠文字层的区域时使用提取文字和本地上下文，不强制发送图像；锚点重启后恢复。

### F. 区域框选图表

首次图像发送显示服务商、模型、内容和费用风险；同意后只发送有界区域；选择“不再提示”只作用于同 profile、同类别。

### G. 多浮动面板

不同对话可同时打开、拖动、缩放和生成；同一对话重复打开只置前；停止一个不影响其他面板。

### H. 隐藏生成面板

生成期间关闭面板后请求继续，重新打开可看到进度/结果；只有停止按钮取消；失败/取消不创建永久标记。

### I. 历史继续与删除

重启后点击标记恢复完整对话并可用当前 profile 续问；删除会话原子移除历史和标记。

### J. 扫描 PDF 拒绝视觉解析

检测到扫描 PDF 时用户可拒绝 AI 索引并继续本地阅读；应用不上传页面，受限页面显示原因。

### K. AI 辅助本地索引

确认后异常页按小批次解析、验证并本地提交；断网或重启后已完成页保留，后续本地搜索不依赖远端。

### L. 部分失败与重试

一页失败不会回滚其他页；书可阅读且显示 `partial`；单页重试成功后聚合状态更新。

### M. 人工纠正

用户修正转写或 LaTeX 后检索优先使用修正；重新识别不会静默覆盖，并能比较冲突。

### N. 来源区分

回答和引用能区分原始文字、AI 转写、AI 描述和用户修正；视觉描述不被标为教材原文。

### O. 响应式窗口和全屏

窄窗口、最大化、全屏、200% 缩放、高对比度和减少动画下，导航、阅读、框选和面板仍可操作且标题栏可见。

### P. 数据备份与恢复

完整备份明确包含教材副本且不含 Key；恢复到缺少凭据的环境后教材、索引、修正、历史和设置存在，并提示重新连接 AI 服务。

### Q. 删除与泄漏检查

删除教材和清除全部数据覆盖所有应用拥有的本地/远程临时资源边界；日志、诊断、备份、IPC 错误和安装产物不泄漏 Key、正文、图像、提示词或回答。

## 18. 完成定义

V1 只有在以下条件同时满足时完成：

- Phase 1–3 既有 checkpoint 未回归；重规划 Phase 4R–15 全部 checkpoint 通过。
- A–Q 自动化或明确的人工门禁均有可复现证据并记录在新验证矩阵。
- 五家文本 provider 共享契约通过；视觉/结构化功能只对官方核实支持的模型开放。
- 三种格式、三种语言、来源/修正、区域锚点、多面板并发、备份恢复和删除均有跨重启测试。
- Rust fmt/clippy/test/deny、前端 format/lint/typecheck/test/build、Playwright、generated、licenses、sensitive、fixtures 和 Windows Tauri 构建全绿。
- clean Windows 11 x64 冒烟通过；至少对每个启用的 provider 能力完成最小真实凭据手工门禁，且不记录敏感内容。
- 工作树只包含明确目标文件；用户的无关 staged/untracked 内容未触碰。

## 19. 施工决策规则

- 本规格与旧文档冲突时，本规格优先；架构细节由 ADR 0005–0010 固定。
- 未知 provider 能力按不支持处理；执行任务时使用官方文档复核并记录 `last_verified`。
- 每个阶段保持应用可运行；数据库只前向迁移。
- 普通任务先运行直接相关的最小测试；跨模块 checkpoint 和发布才运行全量门禁。
- 数据迁移、共享 DTO、provider 协议、请求/持久化原子性、删除/恢复不并行写入。
- 只有明确只读、无依赖的官方协议审计、测试清单或视觉检查可以并行。
- 发现需求必须扩大到本规格明确排除的能力时停止并回到主控台，不自行扩展 V1。
