# TextbookLens 使用手册

[English](user-guide.md) · [简体中文](user-guide.zh-CN.md) · [繁體中文](user-guide.zh-TW.md)

TextbookLens 是面向 Windows 11 x64 的本地优先 PDF、EPUB、DOCX 教材阅读器。切换界面语言不会翻译教材、笔记、问题或回答。

## 安装与开始使用

1. 打开[最新版下载页](https://github.com/gh615280-maker/TextbookLens/releases/latest)。
2. 普通用户选择标准 EXE；集中部署可选择 MSI。电脑没有 WebView2 且无法联网时，选择文件名含 `offline` 的安装包。
3. 可使用 `SHA256SUMS.txt` 核对安装文件。
4. 安装包尚未代码签名，因此 Windows 可能显示“未知发布者”。

首次使用从选择一本教材开始。AI 是可选项：可以用“自动连接本地 AI”接入已安装的 Ollama/LM Studio，也可以配置支持的云端服务，或者只使用本地阅读功能。

## 导入与阅读

1. 在“书库”点击“导入”或拖入 PDF、EPUB、DOCX。TextbookLens 会先把文件复制到应用自己的本地数据区，再进行解析和索引。
2. 搜索、阅读位置、笔记、批注和已完成问答历史保存在本地。
3. 选中文字后可以解释、举例、逐步推导、翻译、提问或创建笔记。
4. 用“框选”选择公式、图表、插图或其他区域。视觉请求首次发送前会显示服务商、模型、内容类型、图片数量和风险。
5. 完成的回答会成为标记和浮动面板。“隐藏”只关闭面板，“停止”才会取消正在运行的请求。可以从标记或历史重新打开回答。

## 提问与上下文

TextbookLens 按教材保存学习记录，避免内容散落在多个互不关联的聊天窗口中。每次提问会组合有限的选中内容、当前教材的相关检索结果、必要的本书历史、当前教学指令和问题。它不会发送整个书库，也不会消除 AI 模型本身的上下文上限。

教材的“学习概览”完全在本地生成。完成全文准备后可以整本提问，但只检索当前教材的相关内容。普通 PDF 文字层、EPUB 和 DOCX 的文字提取不需要 AI 模型。

## 本地与云端 AI

- **Ollama：** 一键发现可启动本地服务、查找已安装文字模型、用合成问题测试模型并创建可用 profile；兼容的视觉模型可单独选择。
- **LM Studio：** 本地文字接入仍为实验性功能，真实机器验证留到 v0.2.1；不承诺视觉输入。
- **云端服务：** OpenAI、Gemini、Anthropic、DeepSeek 和 Kimi 需要用户自己的 API Key，密钥通过 Windows 凭据管理器保存。
- TextbookLens 不安装运行环境、不下载模型、不附带模型权重，也不会在本地 AI 失败后静默切换到云端。

详情见 [AI 服务](ai-services.zh-CN.md)和[离线本地模型](local-models.zh-CN.md)。

## 哪些数据保留本地，哪些可能发送

| 数据或操作                               | 本地行为                                  | 是否需要明确操作才发送 |
| ---------------------------------------- | ----------------------------------------- | ---------------------- |
| 导入副本、标准化章节、本地索引、阅读位置 | 应用自有文件和 SQLite                     | 否                     |
| 阅读、搜索、笔记、标记、已完成历史、语言 | 保留本地，可离线使用                      | 否                     |
| 设置、教学指令、profile 元数据、确认选择 | 保留本地；云端密钥使用 Windows 凭据管理器 | 否                     |
| 选中文字或续问                           | 冻结的选区和有限的本书上下文              | 是                     |
| 选中区域图片                             | 确认前仅在本地暂存有限截图                | 是                     |
| AI 辅助异常页索引                        | 本地检测和校验                            | 是，只发送已确认页面   |
| Kimi Files 全文准备                      | 结果和本地索引留在本机                    | 是，只发送所选 PDF     |
| 整本提问                                 | 只检索当前教材的相关内容                  | 是                     |

拒绝确认就不会发送。记住的选择只适用于对应 profile 和内容类别，不能授权后台上传。

## 备份、删除与恢复

“创建备份”生成带版本的 `.tlbackup`，包含应用自有教材副本和本地学习数据，但不包含 API Key、日志、临时截图、绝对源路径或未完成 AI 输出。“恢复备份”会先校验版本、路径、大小、哈希和 SQLite 完整性，再安排原子重启替换。

“从书库移除”只删除一本应用自有副本及其相关本地记录，不会删除原始文件。“清除全部数据”需要输入准确确认文本，并删除 TextbookLens 本地数据和凭据；单独保存的备份与原始教材不在目标范围内。卸载不等同于数据清除。详情见[数据、备份、恢复与删除](data-backup.zh-CN.md)。

## 当前限制

- 只支持 Windows 11 x64；安装包未签名，也没有自动更新。
- 尚未实现本地全书 OCR 和本地全书视觉索引。
- 本地视觉模型可能在密集图表、手写内容或复杂公式上给出错误答案。
- 大型扫描 PDF 可能需要手动调整缩放。
- 服务可用性、额度、价格、保留策略和回答质量由对应服务商或模型决定，不由 TextbookLens 保证。
