# TextbookLens roadmap

This roadmap communicates direction rather than a delivery promise. Priorities may change after user feedback and reliability work.

## Now — strengthen the first public release

- Collect reproducible reports from different Windows 11 x64 environments.
- Improve importer, reader, index, backup, and restore reliability.
- Complete outstanding manual accessibility and provider checks.
- Keep release evidence, checksums, and privacy boundaries easy to audit.

## Next — make installation and daily use easier

- Add trusted code signing and timestamping when sustainable.
- Design a transparent, user-controlled update path.
- Improve first-run guidance, empty states, and large-library navigation.
- Expand reader ergonomics and annotation workflows from validated user requests.

## Later — carefully widen support

- Evaluate additional Windows architectures and operating systems based on demand and maintenance cost.
- Consider more import formats only when they can preserve the local-first security model.
- Improve extension points for optional AI providers without moving provider traffic into the frontend.

## What is intentionally out of scope today

Accounts, cloud sync, collaboration, a project proxy, bundled model credit, web/mobile clients, and silent background uploads are not part of the current product boundary.

To influence priorities, open a [feature request](https://github.com/gh615280-maker/TextbookLens/issues/new/choose) with the user problem, expected workflow, and why existing behavior is insufficient.
